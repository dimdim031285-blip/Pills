# Таблетки — дневник приёма

GitHub-ready мини-приложение для учёта приёма препаратов.

- Один препарат = одна строка.
- Несколько приёмов одного препарата = несколько галочек в разных временных колонках.
- Препараты идут строго в порядке добавления, без алфавитной сортировки.
- Кнопка «Список на завтра» дублирует текущий список без отметок о приёме.
- Есть архив дней и резервное сохранение JSON.
- Поддерживается установка как PWA через GitHub Pages.

## GitHub Pages
Загрузите все файлы в репозиторий и включите Settings → Pages → Deploy from branch → main → root.
После публикации откройте сайт на Android и выберите «Установить приложение» / «Добавить на главный экран».
